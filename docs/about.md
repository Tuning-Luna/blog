## 关于本站

本站基于 **VitePress** 构建，纯静态、无后端，由 GitHub Actions 在每次 `git push` 后自动构建并部署到 GitHub Pages。

- **内容**：Markdown 文章，统一放在 `docs/blog/posts/`
- **主题**：Material Design 3 × Glassmorphism 设计系统（复用 `design-system/`）
- **技术栈**：VitePress · Vue 3 · TypeScript · npm · GitHub Actions · GitHub Pages
