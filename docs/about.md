# About

我是 Tuning-Luna，合肥工业大学（HFUT）宣城校区计算机科学（CS）专业的学生。

喜欢折腾技术、动手写代码：把课程设计、实验与学习资料整理成开源项目（比如 [HFUT_XC_Study_Things](https://github.com/Tuning-Luna/HFUT_XC_Study_Things)），也写爬虫、逆向与全栈应用。信奉「Always Learning, Always Building」——代码是最接近魔法的东西。

## 关注的方向

- Web 全栈
- 爬虫与逆向
- 机器学习
- 开源与学习资料

## 关于本站

本站基于 **VitePress** 构建，纯静态、无后端，由 GitHub Actions 在每次 `git push` 后自动构建并部署到 GitHub Pages。

- **内容**：Markdown 文章，统一放在 `docs/blog/posts/`
- **主题**：Material Design 3 × Glassmorphism 设计系统（复用 `design-system/`）
- **GitHub 信息**：首页统计与项目来自 GitHub 公开数据快照，每天自动刷新
- **源码**：<https://github.com/Tuning-Luna/tuningluna-blog>
