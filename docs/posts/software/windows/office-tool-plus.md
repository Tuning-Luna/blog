微软官方 Office 部署工具（ODT）的图形界面。选版本、选组件（Word / Excel / PowerPoint / Visio / Project 等）、选语言，一键下载部署；也能修改已经装好的 Office（增删组件和语言）、把配置导出成文件或命令、做离线安装包。文件都从微软官方服务器下载。

要说清楚的是，它只负责**部署和管理**，不含激活 —— 这点和 [Mocreak](/posts/software/windows/mocreak) 不一样，后者是一键部署加激活。两者用途相邻，按需选一个即可。
