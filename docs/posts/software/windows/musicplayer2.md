本地音乐播放器，功能给得很足：歌词显示、歌词卡拉OK 样式、歌词在线下载与编辑、专辑封面自动匹配、频谱分析、均衡器与混响、格式转换、CUE 分轨，界面布局还能用 XML 自定义。播放内核支持 BASS 和 FFmpeg 两套，常见的音频格式基本都吃。

只支持 Windows，需要先装 Visual C++ 运行库。

- GitHub：https://github.com/zhongyang219/MusicPlayer2 （6.7K Stars）
