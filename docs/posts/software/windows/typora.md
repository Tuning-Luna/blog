写 Markdown 不用分屏 —— 输入就即时渲染成最终样式，所见即所得，也没有源码和预览的模式切换。表格、代码块、公式、图表都能直接渲染，主题用 CSS 自定义。跨 Windows / macOS / Linux。

要说明的是，Typora 是**商业软件**，不是免费软件：15 天试用，之后 $14.99（不含税）授权 3 台设备。

- 官网：https://typora.io/
