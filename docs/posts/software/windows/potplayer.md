有两点得说清楚：它是**闭源免费软件**，不是开源项目；另外安装器过去有过捆绑和广告位的争议，各区、各版本情况说法不一，我不下结论，但**建议只从官网下载** —— 第三方下载站提供的「去广告版 / 绿色版」改了什么无从验证。

官网在境外，国内直连可能不稳定。

- 官网：https://potplayer.daum.net/
