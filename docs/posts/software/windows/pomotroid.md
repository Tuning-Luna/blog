番茄工作法的计时器，界面干净不花哨，该有的都有：时长可自定义、统计面板（图表加 52 周热力图）、全局快捷键、38 套内置主题，还带一个可选的 WebSocket 服务方便和别的东西联动。基于 Tauri 2。

一个小提醒：官方说明目前**没有做代码签名**，首次启动系统会弹一次警告，属预期行为。

- 官网：https://pomotroid.app/
- GitHub：https://github.com/Splode/pomotroid （5.5K Stars）
