桌面上的猫咪会跟着你的操作动 —— 敲键盘它跟着敲，移动鼠标它的眼睛和脑袋会转过来，手柄的摇杆和按键也能识别。

基于 Tauri 构建，跨 Windows / macOS / Linux。窗口大小、不透明度、鼠标穿透都可以调，也支持导入自定义 Live2D 模型。完全离线运行，不收集数据。

- GitHub：https://github.com/ayangweb/BongoCat （23.5K Stars）
