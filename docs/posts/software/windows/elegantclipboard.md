低占用、高性能、现代化、高度自定义，本地化离线剪贴板。使用了Tauri框架+Rust后端，可以说兼具美观和性能了。

比WIndows自带的Win+V呼出的剪切板相比，多了许多功能，还能解决 [Bitwarden](/posts/software/windows/bitwarden) 使用 Random Generate Password 无法复制到Windows自带的剪切板功能。

- GitHub：https://github.com/Y-ASLant/ElegantClipboard
